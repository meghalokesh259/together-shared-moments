# Together — Shared Moments Planner

A small, responsive web app for two people to plan a shared activity, even when they are apart. This is a portfolio learning project inspired by the general idea of making long-distance time together easier; it is not affiliated with Kulfi.

## Features
- Add a shared activity with a title, category, and planned time.
- Mark an activity as completed.
- Delete an activity.
- Empty state when no activities exist.
- Input validation and clear feedback.
- Saves activities in the browser with `localStorage`.

## Tech stack
HTML, CSS, vanilla JavaScript, browser `localStorage`.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser. No build tools or server are required.

## What I built
This project demonstrates a simple UI, client-side state updates, validation, empty states, and persistence in the browser.

## Current limitations / next improvements
- Data is stored only in the current browser; there is no shared cloud database or login.
- Add automated tests.
- Add a backend API and real-time sync so both people can see the same plan.

## Portfolio honesty
This is a personal practice project. It is not a production app and does not currently sync between users.
